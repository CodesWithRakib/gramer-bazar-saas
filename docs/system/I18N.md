# Internationalization (i18n) Architecture

## Overview

Gramer Bazar features bilingual support for **English (`en`)** and **Bangla (`bn`)**.

---

## Route Structure

- All Next.js page routes are prefixed by language parameter `/[lang]/...`.
- Supported locales: `en` (Default), `bn`.
- Direction: Left-to-Right (`ltr`) for both English and Bangla text.

---

## Technical Translation Implementation

1. **Dictionaries**: Stored in `apps/web/src/dictionaries/en.json` and `bn.json`.
2. **Database Entities**: Database tables support bilingual fields:
   - Category: `nameEn`, `nameBn`, `descriptionEn`, `descriptionBn`
   - Product: `nameEn`, `nameBn`, `descriptionEn`, `descriptionBn`
   - Unit: `unitEn`, `unitBn`
3. **Language Switcher (`LanguageSwitcher.tsx`)**: Updates path locale and sets persistent cookie `NEXT_LOCALE`.
