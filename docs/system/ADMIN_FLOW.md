# Admin Operational Workflows

## Overview

The Admin portal (`/[lang]/admin`) provides operational control over platform users, applications, marketplace taxonomy, orders, delivery assignments, and financial payouts.

## Operational Modules

### 1. Operations Analytics (`/[lang]/admin`)
- Displays real-time sales volume, total orders, active customer counts, seller counts, and rider counts.

### 2. User & Application Management (`/[lang]/admin/users-management`)
- Lists all registered users across all roles.
- Allows toggling account active/disabled status.
- Reviews seller and rider onboarding applications with one-click Approve / Reject buttons.

### 3. Order & Delivery Control (`/[lang]/admin/orders`)
- Views all platform orders regardless of shop.
- Assigns orders in `READY_FOR_PICKUP` status to available delivery riders.

### 4. Catalog Management (`/[lang]/admin/products`)
- Manages global categories, subcategories, and brands.
- Reviews and approves seller product submissions.

### 5. Financial Payout Approval (`/[lang]/admin/finance`)
- Reviews seller and rider wallet withdrawal requests.
- Verifies bank / bKash account details and approves or rejects payouts.
