# Sports & Fitness Structured Attributes Dictionary

Structured attributes define technical specifications and variant axes across sports equipment, activewear, and athletic footwear.

| Slug | Data Type | Filterable | Variant Axis | Description & Sample Values |
| --- | --- | --- | --- | --- |
| `sports-type` | SELECT | Yes | No | Sport or athletic discipline (Football, Cricket, Badminton, Tennis, Basketball, Gym & Fitness, Yoga, Cycling, Boxing, Swimming) |
| `sports-activity` | SELECT | Yes | No | Intended physical activity (Running, Gym & Strength Training, Cardio & Endurance, Match & Tournament, Daily Practice, Yoga) |
| `sports-skill-level` | SELECT | Yes | No | Athlete skill tier (Beginner, Intermediate, Advanced, Professional / Match Grade, All Skill Levels) |
| `sports-gender` | SELECT | Yes | No | Target gender specification (Men, Women, Boys, Girls, Unisex, Kids) |
| `sports-material` | SELECT | Yes | No | Core equipment / apparel material (English Willow, Kashmir Willow, Carbon Graphite, PU Leather, Solid Cast Iron, Eco TPE, Aluminum Alloy, Dry-Fit Polyester) |
| `sports-size` | SELECT | Yes | Yes | Ball size (Size 3, 4, 5), cricket bat size (SH, LH), apparel size (S-XXL), bike wheel size (26", 27.5", 29") |
| `sports-weight-capacity` | SELECT | Yes | Yes | Equipment weight / user capacity (2.5 kg, 5 kg, 10 kg, 15 kg, 77g 5U, 83g 4U, Max User 120 kg) |
| `sports-glove-size` | SELECT | Yes | Yes | Boxing & keeper glove weight/size (8 oz, 10 oz, 12 oz, 14 oz, 16 oz, Size 7-10) |
| `sports-footwear-size` | SELECT | Yes | Yes | European shoe size standard (EU 39 through EU 45) |
| `sports-pack-size` | SELECT | Yes | Yes | Pack configuration (1 Piece, Pair of 2, Tube of 6, Tube of 12, Set of 3, Full Kit) |
| `sports-warranty` | SELECT | Yes | No | Manufacturer / importer warranty (No Warranty, 6 Months, 1 Year Official Brand, 2 Years Motor/Frame Service) |
| `sports-country-of-origin` | SELECT | Yes | No | Country of production (Bangladesh, India, Japan, UK, USA, Germany, France, China, Taiwan, Pakistan) |
