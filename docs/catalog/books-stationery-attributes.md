# Books & Stationery Structured Attributes Dictionary

Structured attributes define technical specifications and variant axes across books, paper products, and writing instruments.

| Slug | Data Type | Filterable | Variant Axis | Description & Sample Values |
| --- | --- | --- | --- | --- |
| `book-author` | SELECT | Yes | No | Author or creator attribution (Humayun Ahmed, Tamim Shahriar Subeen, James Clear, Imam Ghazali) |
| `book-publisher` | SELECT | Yes | No | Publishing house or imprint (Prothoma Prokashon, Batighar, Dimik, George Series, Rahmaniya) |
| `book-isbn` | SELECT | Yes | No | Validated standard ISBN-10 or ISBN-13 identifier |
| `book-language` | SELECT | Yes | No | Text language (Bangla, English, Arabic, Bilingual) |
| `book-format` | SELECT | Yes | Yes | Binding format (Paperback, Hardcover, Board Book, Spiral Bound) |
| `book-edition` | SELECT | Yes | No | Publication edition (1st Edition, Revised Edition 2026, Student Edition) |
| `book-pages` | SELECT | Yes | No | Book page count (160 Pages, 256 Pages, 320 Pages, 512 Pages) |
| `book-genre` | SELECT | Yes | No | Book subject / genre (Fiction & Novel, Computer & Programming, Self-Development, Academic) |
| `book-paper-size` | SELECT | Yes | Yes | Page or sheet format (A4, A5, B5, Legal, Letter) |
| `book-paper-gsm` | SELECT | Yes | Yes | Paper weight / density (65 GSM, 70 GSM, 80 GSM, 100 GSM, 120 GSM) |
| `book-paper-type` | SELECT | Yes | No | Ruling or texture (Ruled / Lined, Plain / Unruled, Grid / Graph, Dot Grid, Offset) |
| `book-pack-size` | SELECT | Yes | Yes | Quantity in bundle (1 Piece, Pack of 5, Pack of 10, Ream of 500 Sheets, Box of 5 Reams) |
| `book-ink-color` | SELECT | Yes | Yes | Writing instrument ink color (Blue Ink, Black Ink, Red Ink, Assorted) |
